# Ecommerce Data Dashboard

This project is an interactive Excel-based ecommerce dashboard created to analyze sales, customer behavior, delivery performance, 
and product trends. The dashboard provides a clear visual summary of ecommerce transactions, helping users understand key business
metrics such as total orders, quantity sold, revenue, average customer rating, and average delivery time.

The dataset focuses on ecommerce sales activity across California and includes customer details, product categories, order modes, 
ratings, shipping information, and location-based insights.

## Key Features

- Summary cards for total orders, quantity sold, total amount, average rating, and delivery days
- Quantity and amount trend analysis
- Preferred buying mode comparison by customer gender
- Product popularity analysis by gender
- Customer location visualization using a California map
- Quantity purchase distribution
- Delivery time analysis
- Customer rating breakdown
- Interactive filters for order mode and gender

## Dataset Information

The dataset contains ecommerce transaction records with fields such as:

- Transaction ID
- Product
- Quantity
- Unit Price
- Amount
- Order Date
- Ship Date
- Customer Gender
- Order Mode
- Customer Rating
- State
- County
- Days to Deliver

## Dashboard Insights

The dashboard helps identify:

- Which products are most popular among different gender groups
- Which order modes customers prefer
- How sales quantity and amount change over time
- Average customer satisfaction through ratings
- Delivery performance based on shipping days
- Geographic distribution of customers across California
